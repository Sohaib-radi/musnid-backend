# ADR 0001: Python 3.12

## Status

Accepted, 2026-10-04.

## Context

The backend will use CrewAI 1.9.3 for its AI agents (installed in a later step). The
Python version must satisfy CrewAI and its dependency tree on every platform where the
project runs:

- the development machine: macOS 12.7.6 on Intel (`x86_64`);
- Docker images on Linux `x86_64` and `aarch64`.

Two constraints were verified against the PyPI JSON API on 2026-10-04:

1. **CrewAI 1.9.3 supports Python `>=3.10,<3.14`.** This is the `requires_python` value
   of the `crewai` 1.9.3 release.
2. **onnxruntime limits the macOS version, and through it the Python version.** CrewAI
   1.9.3 requires `chromadb~=1.1.0`, and chromadb 1.1.1 requires `onnxruntime>=1.14.1`.
   onnxruntime publishes binary wheels only, so the release that can install depends on
   the macOS version its wheels target. Minimum macOS version of the `x86_64` or
   `universal2` wheels, and Python versions with wheels, per release:

   | onnxruntime | Minimum macOS (Intel) | CPython wheels |
   | --- | --- | --- |
   | 1.18.0 to 1.19.2 | 11.0 | 3.8 to 3.12 |
   | 1.20.0 to 1.23.2 | 13.0 | 3.10 to 3.13 |
   | 1.24.1 to 1.30.0 | no Intel macOS wheels | 3.11 to 3.14 |

   **1.19.2 is the last onnxruntime release that installs on macOS 12**, and its newest
   wheels are for **Python 3.12**. On macOS 12 Intel with Python 3.13, no onnxruntime
   release has a compatible wheel, so CrewAI cannot be installed.

## Decision

Use **Python 3.12** everywhere:

- local virtualenv created with `python3.12`;
- Docker image `python:3.12-slim`.

Python 3.12 is the newest version that satisfies both constraints: it is within
CrewAI's supported range and has onnxruntime 1.19.2 wheels for macOS 12 Intel.
Linux images could use 3.13, but running the same minor version on the development
machine and in Docker avoids a class of "works locally" differences.

## Consequences

- On macOS 12 Intel, onnxruntime is effectively capped at 1.19.2. When CrewAI is
  installed, that version must be pinned or allowed to resolve, and newer onnxruntime
  features are unavailable on this machine.
- Python 3.13+ features cannot be used.
- Moving to Python 3.13 or later requires either a development machine on macOS 13 or
  newer (for onnxruntime 1.20 to 1.23) or an onnxruntime-free dependency tree; Intel
  macOS is not supported at all from onnxruntime 1.24.
- Python 3.12 receives security fixes until October 2028, which covers the project's
  expected lifetime.
